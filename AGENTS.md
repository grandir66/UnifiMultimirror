# AGENTS.md — Script_Ubiquiti (UnifiMultimirror)

Mirroring multiplo delle porte UniFi: genera la configurazione che il controller non
prevede di default. Python (`main.py`, `script_generator.py`, `config_parser.py`);
installazione e uso nel `README.md` (`setup_and_run.sh`).

## Regole del repo

- Resta, anche se non sviluppato: è uno strumento usato (decisione nel censimento).

## Regole comuni (qui non si ricopiano)

Valgono le regole dell'area in `~/Progetti/AGENTS.md` e quelle di comportamento in
`~/.claude/AGENTS.md` (contesto su disco in `CONTEXT.md`, niente prove a caso,
loop di fine sessione). Questo file dice solo ciò che è di questo repo.
